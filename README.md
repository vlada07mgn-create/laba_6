# Программа для обработки анкет

Эта программа читает файл с анкетами, проверяет корректность данных (ФИО, почта, телефон, группа), выводит красивую таблицу в консоль и сохраняет результаты.
## Как запустить
1. Убедитесь, что у вас установлен Python.
2. Поместите файл с данными `anketa.txt` в папку с проектом.
3. Запустите главный файл:
   ```bash
   python main.py
